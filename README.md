# MiniTracker

MiniTracker is a mobile project management app for Warhammer miniature hobbying.

## What it includes

- Expo-powered React Native starter app
- Local project tracking for miniature builds, factions, painting status, and notes
- Sample GitHub Actions workflow for lint validation
- TypeScript support and local persistence with AsyncStorage

## Getting started

1. Install dependencies:

```bash
npm install
```

2. Start the app:

```bash
npm start
```

3. Open on a device or emulator using Expo.

## GitHub workflow

This repository includes `.github/workflows/ci.yml` for lint checks on `push` and `pull_request`.

## How to use the app

- Add a new project using the form
- Track your army faction, backlog status, and painting stage
- Attach photos to project entries
- Write detailed notes for each project
- Toggle completed projects and delete old entries
